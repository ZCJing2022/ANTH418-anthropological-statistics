Assignments

The ten ANTH418 assignments use published archaeological and anthropological datasets.

Each assignment package contains:

  • assignment .qmd;
  • README;
  • codebook;
  • provenance note; and
  • teaching dataset.

Students may browse the materials online or download the complete assignment package as a ZIP file.
