How to use this workbook

Week 3 established that measurement and research design determine what numerical summaries can legitimately mean. Week 4 asks:

Where is the center of a distribution, how widely do observations vary, and which summaries describe the empirical pattern responsibly?

inspect the distribution → locate the center → quantify spread → check resistance → compare summaries → interpret the empirical pattern

The governing principle is describe before explaining.

Learning objectives

By the end, you should be able to calculate and interpret mode, median, mean, trimmed mean, range, IQR, variance, standard deviation, MAD, and CV; inspect distributions with histograms and boxplots; choose defensible summaries; calculate grouped descriptives; and separate statistical description from archaeological explanation.

Part I — Measurement level comes first

1. Match the statistic to the variable

Measurement level Useful center Useful spread
Nominal Mode counts / proportions
Ordinal Median, mode IQR, range
Interval Mean, median, mode SD, variance, IQR
Ratio Mean, median, mode SD, variance, IQR, CV

Part XII — Grouped descriptive statistics

19. Center and spread together

summary_tbl <- iso_long |>
  group_by(site, isotope) |>
  summarise(
    n = sum(!is.na(value)),
    mean = mean(value, na.rm = TRUE),
    median = median(value, na.rm = TRUE),
    sd = sd(value, na.rm = TRUE),
    q1 = quantile(value, 0.25, na.rm = TRUE),
    q3 = quantile(value, 0.75, na.rm = TRUE),
    iqr = IQR(value, na.rm = TRUE),
    mad = mad(value, constant = 1, na.rm = TRUE),
    min = min(value, na.rm = TRUE),
    max = max(value, na.rm = TRUE),
    range = max(value, na.rm = TRUE) - min(value, na.rm = TRUE),
    .groups = "drop"
  ) |>
  mutate(across(
    c(mean, median, sd, q1, q3, iqr, mad, min, max, range),
    ~ round(.x, 2)
  ))

Part XVII — Conceptual debugging

24. Diagnose the mistake

Identify the problem:

  1. “The mean is always the best center.”
  2. “Same mean means same distribution.”
  3. “Range is robust.”
  4. “The boxplot flagged it, so I deleted it.”
  5. “SD = 2.4, therefore variance = 2.4.”
  6. “La Bastida’s mean is higher, therefore people there necessarily ate more meat.”
  7. “Different sample sizes make descriptive comparison impossible.”
  8. “R calculated it, so it must be meaningful.”
