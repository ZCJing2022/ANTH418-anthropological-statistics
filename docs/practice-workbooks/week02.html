How to use this workbook

This is a learn-by-doing companion to the Week 2 Study Guide. Work from top to bottom. For each exercise use predict → run → inspect → explain.

Week 2 principle: Do not separate doing the analysis from documenting the analysis.

Learning objectives

By the end, you should be able to distinguish R, RStudio, and Quarto; use the Console and Terminal correctly; create objects and vectors; use functions and help; inspect tibbles; use projects and relative paths; import CSV data; use pipes and core dplyr verbs; create a simple plot; understand YAML, Markdown, chunks, and inline R; diagnose common errors; and pass a clean-render test.

Part IX — Debugging

25. Common errors

Object not found: inspect object and column names with names(knipper).

File not found: inspect getwd(), list.files(), and file.exists().

Function not found: check whether the required package is loaded with library().

Unexpected NA: determine whether missing values are present and whether na.rm = TRUE is appropriate.

Debugging checklist

  1. Read the entire error message.
  2. Does the object exist?
  3. Is the name spelled exactly?
  4. Is the required package loaded?
  5. Does the file path exist?
  6. Are missing values involved?
  7. Did an earlier line fail?
  8. Can you reduce the problem to a smaller example?

Part X — Clean render and reproducibility

26. The Clean Render Test

Interactive success is not enough. Old objects may remain in the Environment.

Before considering the workbook complete:

  1. Save the .qmd.
  2. Choose Session → Restart R.
  3. Do not manually recreate objects in the Console.
  4. Click Render.
  5. Confirm the document builds from top to bottom from a clean session.

If the document renders only because an object was left in memory, the analysis is incomplete.
