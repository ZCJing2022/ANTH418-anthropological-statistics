How to use this workbook

Week 5 emphasized that visual choices shape what we see. Week 6 goes one step earlier:

raw values → preparation decisions → transformed/missing-data representation → analysis → conclusion

The central claim is:

Preparation is analysis.

Transformations alter mathematical relationships. Missing-data decisions determine which cases count and what an unknown value is allowed to mean.

visual audit → diagnose → transform or handle missingness deliberately → compare alternatives → sensitivity analysis → document

Learning objectives

By the end, you should be able to diagnose reasons for transformation; compare log, square-root, Box-Cox, and Yeo-Johnson logic; distinguish transformation from z-standardization; explain compositional constraints; distinguish NA from zero and explicit from implicit missingness; explain MCAR, MAR, and MNAR; evaluate deletion and imputation; explain multiple imputation; reproduce the core Seshat sensitivity comparison; and document preparation choices.

Part I — Preparation is analysis

1. Cleaning is not neutral bookkeeping

Consider:

  1. Replace every unknown outcome with 0.
  2. Apply log() to a strongly right-skewed variable.

Both change the data used by later analysis.

Practice 1

Explain what mathematical structure transformation changes, what evidential claim NA → 0 makes, and why both decisions should be reported.

Part II — Why transform a variable?

2. Four problems transformations may address

Week 6 identifies:

  1. Skewness correction
  2. Outlier mitigation
  3. Variance stabilization
  4. Linearizing relationships

A transformation should respond to a diagnosed problem.

3. Right skew and tail compression

library(tidyverse)

set.seed(418)
raw_x <- rexp(300, rate = 0.08)

transform_demo <- tibble(
  raw = raw_x,
  log = log(raw_x),
  sqrt = sqrt(raw_x)
)

transform_demo |>
  pivot_longer(everything(), names_to = "scale", values_to = "value") |>
  ggplot(aes(x = value)) +
  geom_histogram(bins = 30) +
  facet_wrap(~ scale, scales = "free") +
  theme_minimal()

Compare raw, log, and square-root versions. Which compresses the tail most? Why must interpretation name the transformed scale?

Part III — Match the function to the data

4. Common transformation families

Week 6 introduces log transformations for severe right skew and positive values, roots for counts/milder skew, and reciprocal-type transformations for stronger compression.

Practice 2

Why does log(0) create a problem? Why is log(x + 1) an analytical choice rather than a harmless technical fix?

Part IV — Box-Cox and Yeo-Johnson

5. Search a transformation family

Week 6 presents Box-Cox as a lambda spectrum: approximately no transformation at λ = 1, square root at λ = .5, log at λ = 0, and stronger inverse-style transformations at negative lambda. Box-Cox requires positive data; Yeo-Johnson extends the logic to zero and negative values.

Practice 3

For values -2, 0, 3, 7, 20, explain why ordinary Box-Cox is not directly appropriate and why Yeo-Johnson might be considered.

Part IX — Missing-data mechanisms

10. MCAR, MAR, MNAR

  • MCAR: missingness is independent of observed and unobserved values.
  • MAR: missingness depends on other observed variables.
  • MNAR: missingness depends on the unobserved value itself or latent causes.

Practice 6

Classify and justify:

  1. A random scanner malfunction deletes 5% of measurements.
  2. Older excavation records are more likely to lack coordinates, and record age is known.
  3. High-status burials are systematically underreported because access was politically restricted.

Why is mechanism a substantive question rather than something R can determine automatically?

tibble(

Part XVI — The Seshat missing-data debate

18. Why coding mattered

The Week 6 lecture uses the Seshat debate to show that unknown observations were treated as recorded absences in the disputed analysis. With extensive missingness, this decision strongly shaped the apparent pattern.

Recoding unknown as absent imposes a historical claim onto unknown cases.

The lecture also highlights forward bias: if beliefs can exist before written documentation, coding unrecorded earlier periods as absence can push apparent origins later.

Practice 9

Explain:

possible belief → no written record → unknown status

versus

possible belief → no written record → recoded 0 → apparent absence

Why can the second pathway manufacture a temporal pattern?

Part XVII — What sensitivity analysis establishes

19. Do not overclaim

This exercise shows that the descriptive pattern is highly sensitive to missing-data treatment.

It does not, by itself, prove the true value of every missing case, that every missing case should be present, a universal causal sequence, or one uniform missingness mechanism.

Practice 10

Write two paragraphs:

A — What the sensitivity analysis demonstrates

B — What it does not establish

Part XVIII — A practical Week 6 audit

20. Rule set before inference

  1. Visual audit — distributions and missingness.
  2. Diagnose — skew, variance, nonlinearity, missingness.
  3. Preserve semantics — never make NA mean 0 without evidence.
  4. Choose deliberately — transformation, deletion, modeling, imputation.
  5. Compare alternatives — do conclusions change?
  6. Document the pathway — report preparation decisions.

Practice 11

Apply this checklist to the Seshat teaching summary. Which steps can be completed with the aggregate file, and which require original case-level data?

Part XIX — Conceptual debugging

21. Diagnose the mistake

Identify the problem:

  1. “The data are skewed, so I always log-transform them.”
  2. “log(0) failed, so I added 1; that has no analytical consequences.”
  3. “Z-scoring makes a skewed distribution normal.”
  4. “A missing cell is the same as a recorded zero.”
  5. “No row means the count must be zero.”
  6. “Listwise deletion only reduces sample size.”
  7. “Mean imputation is safe because it preserves the mean.”
  8. “MICE discovers the true missing values.”
  9. “The 490 Seshat unknowns were really absences.”
  10. “If two missing-data treatments differ, one is automatically correct.”
