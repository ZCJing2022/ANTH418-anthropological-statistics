How to use this workbook

Week 7 showed why statistics vary from sample to sample. Week 8 uses that variability for inference:

estimate → quantify uncertainty → specify a null model → construct a null distribution → calculate a p-value → return to effect magnitude and archaeology

Bootstrap: How much might my estimate vary?

Permutation: What differences would we expect if the null model held?

A bootstrap distribution is a distribution of estimates. A permutation distribution is a null distribution.

Learning objectives

By the end, you should be able to distinguish point and interval estimates; construct and interpret bootstrap confidence intervals; distinguish bootstrap from permutation; state null and alternative hypotheses; construct a permutation null distribution; interpret a p-value as a tail probability conditional on a null model; explain what a p-value does not measure; distinguish statistical significance from effect magnitude and archaeological significance; and apply the complete workflow to Teotihuacan leporid δ13C data.

Part V — Confidence level is a property of a procedure

5. Repeated-interval thinking

The confidence level refers to long-run performance of the interval-producing procedure under its assumptions.

Practice 5

Explain why this is preferable to saying “there is a 95% probability that the parameter is inside this particular interval.”

Part VI — Hypotheses are statistical models

6. Null and alternative

For a difference between means:

\[ H_0:\mu_1-\mu_2=0 \]

\[ H_A:\mu_1-\mu_2\neq0 \]

The null is a statistical reference model, not necessarily a claim that “nothing happened.”

Practice 6

Why is “the isotope means differ” not equivalent to “people managed leporids”?

Part VII — Permutation logic

7. Shuffle what the null permits

set.seed(420)

perm_demo <- tibble(
  group = rep(c("A", "B"), each = 25),
  value = c(rnorm(25, 10, 2), rnorm(25, 12, 2))
)

obs_diff_demo <- mean(perm_demo$value[perm_demo$group == "B"]) -
  mean(perm_demo$value[perm_demo$group == "A"])

obs_diff_demo
[1] 1.814086
set.seed(421)

perm_null_demo <- tibble(rep = 1:5000) |>
  mutate(
    stat = map_dbl(
      rep,
      ~ {
        shuffled <- sample(perm_demo$group, replace = FALSE)
        mean(perm_demo$value[shuffled == "B"]) -
          mean(perm_demo$value[shuffled == "A"])
      }
    )
  )

ggplot(perm_null_demo, aes(x = stat)) +
  geom_histogram(bins = 40) +
  geom_vline(xintercept = c(-abs(obs_diff_demo), abs(obs_diff_demo))) +
  theme_minimal()

Practice 7

Why is the permutation scheme part of the model rather than merely a computational trick?

Part VIII — The p-value

8. Tail probability under the null

p_demo <- mean(abs(perm_null_demo$stat) >= abs(obs_diff_demo))
p_demo
[1] 0.0028

The p-value asks how unusual a statistic at least this extreme would be if the null model were an adequate description of the data-generating process.

Practice 8

Explain why a p-value is not the probability that H0 is true, the probability that chance caused the result, the effect size, the probability an archaeological explanation is true, or a measure of archaeological importance.

Part IX — Bootstrap and permutation answer different questions

9. Two resampling tools

Procedure What is resampled? Distribution Week 8 question
Bootstrap observations with replacement estimates How much might my estimate vary?
Permutation labels allowed by H0 null statistics What differences would occur if H0 held?

Practice 9

Why is only the permutation distribution a null distribution here?

Part X — Statistical significance is not effect magnitude

10. Three separate questions

  1. How large is the observed effect?
  2. How uncertain is the estimate?
  3. How unusual is the result under a defined null model?

A p-value answers only the third.

Practice 10

Why can a small effect be statistically detectable while an archaeologically important effect can remain uncertain?

Part XX — Return to Teotihuacan archaeology

20. Statistical contrast is not archaeological explanation

The Week 8 lecture emphasizes that Oztoyahualco leporids have higher mean carbon-isotope values than other sampled contexts. Higher δ13C is consistent with greater C4/CAM consumption. Access to cultivated foods can be consistent with human provisioning.

But:

A statistical alternative such as “isotope means differ” is not equivalent to “people managed leporids.”

Archaeological interpretation requires context, chronology, ecology, alternative explanations, and other evidence.

Practice 18

  • why provisioning is not automatically management or breeding;
  • how archaeological context contributes to interpretation; and
  • at least one limitation or alternative explanation.

Part XXI — Statistical versus archaeological significance

21. Return to substantive meaning

Statistical inference evaluates compatibility with a model and uncertainty around estimates. Archaeological significance asks whether the magnitude and pattern matter for understanding past behavior.

Practice 19

Complete:

The statistical analysis establishes __________________________.

The broader archaeological evidence suggests __________________.

Why should these statements not be collapsed into one?

Part XXII — Conceptual debugging

22. Diagnose the mistake

  1. “A 95% CI means there is a 95% probability that the parameter is inside this interval.”
  2. “The bootstrap distribution is the distribution of specimens.”
  3. “Bootstrap and permutation are interchangeable.”
  4. “The null hypothesis means nothing happened.”
  5. “A p-value is the probability that H0 is true.”
  6. “p = .01 means there is a 1% probability that chance caused the result.”
  7. “A small p-value means a large effect.”
  8. “Statistical significance establishes archaeological importance.”
  9. “A significant isotope contrast proves leporid management.”
  10. “Once I have a p-value, I no longer need the estimate or confidence interval.”

Part XXIII — Integrated Week 8 challenge

23. Build the full inferential chain

Using the Teotihuacan teaching data:

  1. Identify the observational unit.
  2. Define the grouping and response variables.
  3. State the direction of the contrast.
  4. Describe both groups.
  5. Calculate the observed difference.
  6. Bootstrap the difference.
  7. Construct a 95% percentile interval.
  8. State H0 and HA.
  9. Build the permutation null distribution.
  10. Calculate the two-sided p-value.
  11. Integrate effect magnitude, uncertainty, and null-model compatibility.
  12. Return to archaeological interpretation.
  13. State at least one alternative explanation or limitation.
  14. Distinguish the statistical result from the archaeological claim.
