How to use this workbook

Week 7 asks how partial observations can support defensible inference.

population → sample → statistic → repeated sampling → sampling distribution → standard error → archaeological interpretation

The central distinction is:

A data distribution describes observations. A sampling distribution describes how a statistic varies across repeated samples.

Simulation makes that distinction visible.

Learning objectives

By the end, you should be able to explain probability as long-run relative frequency; distinguish population, sample, parameter, and statistic; explain major sampling strategies; distinguish sampling error from sampling bias; generate and interpret a sampling distribution; explain standard error and its relation to sample size; explain the Central Limit Theorem at an introductory level; distinguish sample size from sample quality; evaluate selection bias and representativeness; and use p3k14c teaching data to study archaeological sampling.

Part II — Population, sample, parameter, statistic

2. Four terms that must not be confused

  • Population: full target set.
  • Sample: observed subset.
  • Parameter: numerical feature of a population.
  • Statistic: numerical feature calculated from a sample.
set.seed(419)

population <- tibble(
  id = 1:10000,
  age = rgamma(10000, shape = 9, scale = 500)
)

population_mean <- mean(population$age)

one_sample <- population |>
  slice_sample(n = 50)

sample_mean <- mean(one_sample$age)

Part VIII — Sample size changes precision

9. Compare n = 20, 50, and 200

set.seed(424)

simulate_means <- function(sample_n, reps = 2000) {
  tibble(rep = 1:reps) |>
    mutate(
      n = sample_n,
      sample_mean = map_dbl(
        rep,
        ~ population |>
          slice_sample(n = sample_n) |>
          pull(age) |>
          mean()
      )
    )
}

sampling_sizes <- bind_rows(
  simulate_means(20),
  simulate_means(50),
  simulate_means(200)
)

ggplot(sampling_sizes, aes(x = sample_mean)) +
  geom_histogram(bins = 30) +
  facet_wrap(~ n, scales = "free_y") +
  geom_vline(xintercept = population_mean, linetype = 2) +
  theme_minimal()
sampling_sizes |>
  group_by(n) |>
  summarise(
    mean_of_means = mean(sample_mean),
    empirical_se = sd(sample_mean),
    .groups = "drop"
  )

Part XXII — Conceptual debugging

23. Diagnose the mistake

  1. “A random sample should exactly equal the population mean.”
  2. “A sample of 1,000 is automatically representative.”
  3. “Sampling error and sampling bias are the same.”
  4. “A sampling distribution is the histogram of raw observations.”
  5. “Standard error measures variation among individual observations.”
  6. “The CLT means the raw population becomes normal.”
  7. “Increasing n removes selection bias.”
  8. “The p3k14c teaching file is a random sample of all past human activity.”
