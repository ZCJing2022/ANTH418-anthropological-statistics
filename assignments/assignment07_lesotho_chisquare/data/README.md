# Student teaching data

`lesotho_raw_material.csv` is the frozen Assignment 7 teaching dataset
derived reproducibly from the published Sehonghong flake source data.

It contains **1,060 source observations** across BAS, RBL-CLBRF, RF, and
BARF and preserves all seven source raw-material categories used in the
teaching frame.

Do not edit the generated CSV manually. See `../provenance.md` and
`../codebook.md` for source, transformations, variables, and analytical
scope.
