# Assignment 9 — Hawaiian Kukui Isotopes

Open `assignment09_kukui_correlation.qmd` for the assignment instructions. Read the case study linked there and consult the codebook and provenance note.

Extract the entire ZIP and keep the `data/` folder beside the QMD. You need R, Quarto and the R package tidyverse. If needed, run `install.packages("tidyverse")` in the R console.

From the extracted folder, run `quarto render assignment09_kukui_correlation.qmd` or use **Render** in RStudio. Render once before editing to check your setup. Add your name to the QMD header if required for submission, then fill in your code and interpretations.
