# Assignment 8 — Roman-Period Iron-Smelting Geochemistry

Open `assignment08_iron_anova.qmd` for the assignment instructions. Read the case study linked there and use the codebook and provenance note to interpret the dataset.

Extract the entire ZIP before opening the QMD. Keep the `data/` folder alongside it. You need R, Quarto, and the R package tidyverse. If needed, install tidyverse from the R console with `install.packages("tidyverse")`.

From the extracted folder, run `quarto render assignment08_iron_anova.qmd` or use **Render** in RStudio. Render once before editing to check your setup. Add your name to the QMD header if required for submission, then fill in your code and interpretations.
