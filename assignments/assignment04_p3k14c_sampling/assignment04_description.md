# Assignment 4: Sampling Archaeological Radiocarbon Data

## Case Study

The p3k14c project assembled a large global database of archaeological
radiocarbon determinations for comparative research while also
documenting important differences in data quality and sampling coverage
(Bird et al., 2022). For this exercise, you will use a **frozen Southern
California subset of 984 radiocarbon determinations** derived from
p3k14c. For teaching purposes, this complete file will be treated as the
**reference population** from which samples can be drawn.

## Assignment

Using the provided radiocarbon dataset, investigate how **random
sampling, sample size, and sampling bias** affect estimates of the mean
conventional radiocarbon age. The objective is to apply the Week 7
concepts of **population and sample, parameter and statistic, sampling
variability, sampling distributions, standard error, and
representativeness** to an archaeological dataset.

First, use repeated random sampling to examine the **sampling
distribution of the sample mean** at different sample sizes. Compare the
center and spread of these distributions and explain how increasing
sample size affects sampling variability and standard error. Then
compare random sampling with a deliberately **restricted sampling
frame** provided in the exercise. Determine whether increasing the
number of observations from this restricted frame removes the difference
between its estimates and the reference population.

Your interpretation should distinguish clearly between **sampling
variability and sampling bias**. Larger random samples generally produce
more precise estimates, but a large sample drawn from an
unrepresentative frame can remain systematically biased. For this
exercise, treat conventional radiocarbon age as a numerical variable for
studying sampling behavior; **radiocarbon calibration, summed
probability distributions, and paleodemographic inference are not
required**.

## Submission

Submit **both** of the following files:

1.  Completed Quarto source file (`.qmd`)
2.  Rendered HTML file (`.html`)

The report should present the required sampling distributions,
comparisons, visualizations, and a concise archaeological/statistical
