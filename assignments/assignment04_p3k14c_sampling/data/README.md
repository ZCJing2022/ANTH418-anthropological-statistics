# Student Teaching Data

`p3k14c_sampling.csv` is the frozen teaching dataset for ANTH418 Assignment 4.

- 984 radiocarbon determinations
- Southern California case-study subset derived from p3k14c
- one row = one radiocarbon determination
- `age` = conventional uncalibrated radiocarbon age in years BP

Do **not** edit the CSV manually.

See the parent folder's `codebook.md` for variable definitions and `provenance.md` for the source and construction of the teaching subset.
